# 本地记录工具

只有用户明确要求保存、更新、删除、导出或备份，或已明确开启相应持续记录时才操作。先确认保存内容、路径和是否含姓名/原话；删除须明确记录 ID；导出、备份须明确目标路径和范围。不要将整个对话、凭据、附件或无关个人信息自动写入。数据内容通过标准输入 JSON 传递，不放进命令行参数、日志或外部服务。常见凭据模式的过滤不完整，操作者仍须检查内容。

本工具使用 Python 标准库和 SQLite。未指定路径时，以当前获授权项目根目录下的 `survival-records/records.sqlite3` 为候选；调用前确认工作目录确实是用户授权的项目根目录，并检查实际目录和文件权限。跨项目用户数据目录仅在用户明确选择时使用；传入 `--db` 必须是获授权的绝对路径。宿主限制路径时，不得静默换目录或绕过授权；应告知未保存并让用户选择获授权的位置。Windows 下会保守检查目录与已有数据库 ACL，只接受当前账户、系统、管理员及当前账户为所有者时的 OWNER RIGHTS；其他许可主体或无法核实时拒绝操作，提示用户选择受控位置。类 Unix 系统对现存目录和数据库检查所有者及 group/other 模式位，未经验证的情况拒绝。程序不会自动修改既有目录权限。该检查无法排除管理员、同一账户进程、备份或权限并发变化等风险。

脚本为 `survival/scripts/records.py`。从当前已安装 skill 的目录定位脚本；以 JSON 对象通过 stdin 提供参数。操作及允许字段：

- `add`：`summary` 必填；可选 `facts`、`uncertainties`、`next_step`、`source`。返回 `id` 和路径。
- `list`：空对象；返回所有记录。
- `get`：`id` 正整数。
- `update`：`id` 加一个或多个允许的记录字段；未指定字段保持原值；可用 JSON null 清除除摘要以外的字段。
- `delete`：`id`。仅删除数据库中的记录，不能保证磁盘、快照或备份中的残留被擦除。
- `export`、`backup`：`destination` 为授权的绝对路径；必须不存在且父目录已存在。导出全部记录为 UTF-8 JSON；备份通过 SQLite 在线备份 API 创建一致性副本。不会覆盖现有文件。

除 `add` 外，数据库不存在时均不创建文件。错误时返回非零状态，不得说成功，也不得打印、泄露用户输入。默认 SQLite 不加密；数据库、日志、备份和导出都可能包含敏感内容。记录不构成自动有效的法律证据；应按地区及组织规则决定合法保全方式。
