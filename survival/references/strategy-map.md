# 兵法精髓到职场战法

本表不是“引用一句古文就有策略”。每一篇都对应一个决策问题、一个正当动作和一个不能跨越的边界。

| 兵法脉络 | 先要解决的决策问题 | 可用职场战法 | 不可用的误读 |
|---|---|---|---|
| 《孙子·计》 | 值不值得争、在哪争、何时争 | 五事七计评估、胜利条件排序、不可逆时间点 | 情绪上头就“先发制人” |
| 《作战》 | 这场消耗是否值得 | 算时间、注意力、信誉、加班、关系与机会成本；设止损 | 长期加班硬撑来证明忠诚 |
| 《谋攻》 | 能否不正面冲突就赢 | 用标准、验收、事实、流程和选项化解冲突 | 把“攻心”理解为操控或羞辱 |
| 《军形》 | 如何让自己不易被击穿 | 任务契约、版本、原始记录、保底交付、复现路径 | 把证据当攻击材料剪辑传播 |
| 《兵势》 | 如何把小优势滚成可信度 | 节奏化交付、固定战报、共同确认、资源前置 | 拉山头或靠人脉压人 |
| 《虚实》 | 哪些能公开、哪些应待证 | 事实/推断/假设分层；将争论引回可验证事项 | 隐瞒关键信息、说假话 |
| 《军争》 | 什么时候快，什么时候稳 | 抢事实首报和决策窗口，同时保护质量与补给 | 以透支团队换一次“抢功” |
| 《九变》 | 变化后怎样不被动 | 预置 if/then 分支、替代供应商、暂停条件 | 随时变脸、朝令夕改 |
| 《行军》《地形》 | 组织真正按什么运行 | 绘权力/信息/资源/流程图，选正确渠道 | 偷拍、监听、获取未授权信息 |
| 《九地》 | 处于何种风险等级 | 将误会、争议、危机、侵害、危险分级处理 | 把所有矛盾都升级为战争 |
| 《火攻》 | 高风险动作是否值得 | 只借其“条件齐备才启动高影响行动”：正式投诉、客户升级、离职均需证据与退路 | 煽动舆论、曝光、毁损关系 |
| 《用间》 | 如何降低信息不对称 | 正常业务记录、授权系统、公开资料、当事人确认、交叉验证 | 套话、钓鱼、盗取、泄密 |

## 正、奇、势、权：四个常被用错的词

- **正**：常规、稳定、可解释的主线。职场就是明确任务、正常渠道、持续交付、固定汇报。它是你的底盘。
- **奇**：不是欺骗，而是对方未准备好的更优解：小范围试点、把模糊指责转成验收题、在风险尚可控时提交替代方案。
- **势**：不是职位压制，而是条件组合后的自然倾向。连续可靠产物、提前风险预警、共同确认，会让组织更倾向于信任你。
- **权**：不是任性变通，而是在目标、规则、代价都清楚后针对具体情况选择路径。权变必须保留可解释的依据。

## 三十六计的安全用法：识别，不施诈

| 常见模式 | 你该识别的职场风险 | 正当应对 |
|---|---|---|
| 声东击西 | 对方用紧急琐事转移你对关键承诺/责任的注意 | 回到任务清单、未决决策和书面确认 |
| 借刀杀人 | 对方让你替其表达攻击、背书或执行越权动作 | 要求授权、目的、范围和责任人写清；拒绝代传攻击 |
| 反间 | 通过传话制造同事互不信任 | 不转述未核实评价；与当事人核对事实 |
| 苦肉计 | 用“我很辛苦/很急”迫使你放弃标准 | 承认压力，但重申验收、资源和风险 |
| 空城计 | 用虚张声势的承诺、客户名头或高层关系逼迫投入 | 要求最小可验证信息、审批和资源承诺 |
| 金蝉脱壳/走为上 | 组织已不再保护规则且风险持续上升 | 先完成交接、证据保全、收入与去向准备，再退出 |

## 资料边界

《武经七书》可作为广泛取材的目录，不意味着每一条军事技术都能迁移到工作。v2 只保留与判断、组织、资源、信息、节奏、正当性和退出有关的内容；明确剔除伤害、欺诈、胁迫和非法情报活动。
