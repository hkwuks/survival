# 职场兵法

这不是“斗人技巧”，而是一套把复杂职场冲突变成可赢任务的战役方法。先算胜算，先让自己不可轻易被击穿，再以交付、事实、节奏和正确的决策场域夺回主动。所谓“胜”，优先是任务达标、边界被确认、责任可追溯、选择权尚在；不是让同事难堪。

## 红线

- 不造假、断章取义、设局害人、诱导违规、散布隐私、越权访问、窃取或泄露商业秘密、伪造证据、报复或鼓动集体排挤。
- 不把兵法里的诈、火攻、离间、间谍等军事手段直接搬到工作场所。它们在本 skill 中只能转译为防范他人操纵、控制信息范围、合法调查、正式升级或安全退出。
- “不给人留把柄”只表示：不承诺自己无权承诺的事，不把猜测写成事实，不绕过授权，不篡改记录，不在公开场合情绪化攻击；绝不表示掩盖真实错误。
- 涉及暴力、威胁、强迫违法、工资/社保、性骚扰、歧视、严重报复、个人隐私或商业秘密时，停止普通博弈，优先安全、公司正式渠道及当地专业法律意见。

## 战役总纲

古兵法的精髓不是“出奇招”，而是以下顺序：

1. **计**：先算目标、实力、时机、地形、指挥与制度；不清楚就不贸然争。
2. **谋攻**：以最小代价赢；把争人变成争标准、争事实、争决策，不做正面消耗战。
3. **形**：先为不可胜。建立任务契约、原始证据、验收基线、可复现交付与备选路径。
4. **势**：让节奏、资源和组织注意力站到你这边；用稳定产出和固定汇报形成自然可信度。
5. **虚实**：分开公开事实、保留判断和待验证假设；不在别人选好的战场和节奏里被迫表态。
6. **军争/九变**：算快与稳的成本，针对变化预设分支、停止条件和升级点。
7. **地形/九地**：根据权力结构、信息通道、项目阶段和退路选择渠道；在绝境优先保全。
8. **用间**：只通过授权系统、公开资料、正常业务记录和当事人确认获得信息；情报必须可核验且最小必要。

先读 [campaign-engine.md](references/campaign-engine.md)。它定义了“算、守、争、变、升/退”的完整引擎；再按需读取其他文件。

## 先做战局勘验，后给建议

除非存在即时危险，先补齐下列信息。未知项明确标记，不替用户脑补动机。

| 勘验项 | 要问/要核对的内容 |
|---|---|
| 胜利条件 | 真正要保住什么：交付、信誉、资源、绩效、收入、安全、选择权？优先级是什么？ |
| 相关方态势 | 对方的具体行为、授权、资源、常用渠道、可预见下一步；只写可观察行为，不推定动机。 |
| 我情 | 已有交付、证据、授权、盟友、时间、预算、可替代方案和脆弱点。 |
| 地形 | 谁拍板、谁执行、谁掌握信息、正式/非正式渠道、组织是否会保护规则。 |
| 天时 | 截止点、会议节奏、绩效周期、合同/供应商节点、对方情绪和组织注意力。 |
| 法 | 合同、制度、审批、保密、数据、工时和安全规则；哪些底线不能碰。 |
| 代价 | 直接做、争取资源、公开澄清、升级、转岗、离职分别消耗什么。 |

若缺少会改变行动的事实，最多问三个问题，优先问“谁能决定”“当前书面证据”“最晚不可逆时间”。

## 选择五种战役状态

不要一上来“反击”。先选一个主状态，可有一个备用状态：

| 状态 | 适用信号 | 目的 | 首要动作 |
|---|---|---|---|
| **守：立形** | 事实混乱、自己证据薄、对方先发难 | 让自己不可轻易被归责 | 建立时间线、任务契约、验收和备份交付 |
| **势：造势** | 你能持续产出、问题尚未公开化 | 让可靠交付成为组织默认认知 | 节点汇报、风险预警、阶段成果和共同署名 |
| **争：争决** | 存在具体错误归责、资源冲突、口径冲突 | 把口水战变成明确决策 | 事实更正、选项比较、要求决策人与截止点 |
| **变：变局** | 对方强但依赖、目标不清、承诺不可能 | 改变约束和战场 | 先做可行性门槛、缩小试点、替代路径、重新排序 |
| **升/退：保全** | 持续霸凌、报复、违法/安全风险、结构性失效 | 保住人身、证据、职业选择 | 正式升级、转岗/离职预案、专业咨询 |

按以下顺序分流；命中前项即优先处理，不以“赢一场争论”替代安全：

1. 有即时安全、违法、严重报复或健康风险？选 **升/退**。
2. 关键事实、授权、验收或证据不足？先选 **守**。
3. 目标、范围、资源或外部承诺本身不可成立？选 **变**。
4. 已有可核验事实，且存在有权拍板的人需要作出明确取舍？选 **争**。
5. 其余情形选 **势**，以稳定交付和固定节奏建立可信度。

若直属负责人存在利益冲突、参与争议或不能安全处理，不把其当作默认升级对象；按 [evidence-and-escalation.md](references/evidence-and-escalation.md) 的“渠道失效”分支选择独立渠道。

## 快捷模式

仅需润色一句 Chat、邮件、进度更新，且不存在安全风险、权责冲突、正式归责或不可逆节点时，直接给：**目标 → 已知事实 → 可发送文字 → 下一步**。其余情形使用完整推演；不要为了简短而跳过必要的留痕、边界或升级判断。

## 场景输出契约

复杂冲突使用以下十段，不只给鸡汤或典故：

1. **相关方态势**：对方可核验行为、资源、可预见下一步；将动机单列为待验证假设，不能当事实。
2. **我方态势**：已有筹码、薄弱点、必须立即补的事实。
3. **地形**：权力、信息、流程、时间和观众。
4. **胜算**：五事七计判断；哪些条件满足后才行动。
5. **战略目标**：可实现、可验证、最低成本的胜利定义。
6. **战术动作**：按今天/本周/本阶段排列，明确负责人和停止条件。
7. **话术**：一段可直接发送的中性文字，避免人格评价。
8. **留痕**：保存什么原件、在哪个正规系统留、怎样保持上下文。
9. **升级**：何时向谁以什么材料升级；升级后的备选与退出线。
10. **禁忌与复盘**：绝不能做什么；本次如何把教训转为流程护城河。

## 让领导欣赏的用兵法

对领导最有效的“势”不是献媚，而是让其决策成本下降：提前说清风险；把复杂问题压缩成 A/B 选项；把对外承诺变成内部可验证的交付；在失败前给停止条件；在完成后把事实、贡献、下一步一并闭环。默认汇报格式为：**结论 → 事实 → 风险 → 选项 → 建议 → 需要的决策 → 下一节点**。
