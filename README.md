# Survival：职场生存与策略 Skill

帮助职场人看清处境、保护安全与权益、维护生计和尊严，并保留职业选择权。结合中国古代兵法中的权变思想和现代组织、谈判、风险管理方法，按实际情境选择行动，不预设同事是敌人，也不把兵法名词当成答案。

适用于职场压力、职责冲突、甩锅抢功、霸凌或报复、资源不足、职业选择，以及需要准备沟通或整理思路的情形。用户可以只要求倾诉、分析或一句能直接使用的话。

## 工作方式

Skill 根据用户的目标、事实和未知、权力与资源、时间窗口、实际风险及可行退路判断；信息不足时只问影响行动的关键问题。它可以建议澄清、协作、设边界、留存合法证据、寻求支持、升级或准备退路，并解释重要前提与代价。对紧急安全或时效风险，优先采取相应行动。

回答结构和长度随场景调整；只有有助于理解时才解释兵法来源。典籍类比不能替代现代证据或具体的法律判断。

## 本地记录

用户可授权本地保存记录并约定内容范围、位置和期限；不默认复制原话或附件。经用户授权可使用本地 SQLite 记录工具，默认候选位置为获授权项目根目录下的 `survival-records/records.sqlite3`，实际使用前仍须通过权限检查；支持查看、更新、删除、导出和一致性备份。SQLite 本身不加密，Windows 文件权限会保守检查，但仍有管理员、同账户进程及权限变化等风险，本地文件可能被其他有权限的人或进程读取。记录不得包含凭据，也不得未经授权上传或提交。详见 [项目上下文与记录](survival/references/project-context-and-records.md)。

## 使用

将仓库内的 `survival/` 作为 Skill 使用，然后描述实际情况，例如：

```text
$survival：老板在群里说项目延期是我的责任，但依赖团队晚了两周。明天要汇报，我怎样澄清，同时保护自己的绩效？
```

不协助造假、报复、欺骗、越权取证或泄露隐私、商业秘密。涉及劳动权益、严重报复、威胁或健康问题时，应根据情况寻求独立支持和当地专业意见；不能保证具体结果。
